# 4階、異常なし。

深夜の警備アルバイト。交代直前の監視カメラ映像を見て、異常があれば［報告］を押すだけの約45〜60秒のホラー。急に驚かせる演出はなし。

## 遊び方（ローカル）

```
node serve.cjs
```

http://127.0.0.1:8088/ を開く（ポートは環境変数 PORT で変更可）。音声と画像を読み込むため、index.html を直接ダブルクリックで開くのではなくサーバー経由で開く。

## 公開に必要なファイル

`index.html`、`og-shift.png`、`voice/`、`img/`、`.nojekyll`。`work/` と `tools/` は作業用（`work/` は .gitignore 済み）。

費用は0円。外部ライブラリ・外部通信・アクセス解析なし。声と画像は事前に生成してファイルとして同梱しているので、遊ぶ人が増えても API 料金は発生しない。

公開URLが決まったら、index.html の `og:image` を絶対URL（`https://…/og-shift.png`）に書き換えると X でも画像付きで表示される。

## しくみ

- 時間割は毎回ランダム。廊下パート → 警備室（CAM 00）→ 暗転。エンディングまで通常 約45〜59秒、9人目 約54〜59秒
- 異常は毎回5〜7個。種類・順番・出る時刻・位置がランダム（扉が開く／照明が消える／手形／足あと／靴／非常口が赤い／扉のすき間から覗く／時刻表示が止まる／床に物：椅子・車椅子・人形・傘・ランドセル・風船・段ボール箱）。遠くの人影・近くの人影も出る
- 無線は場面ごとに3通りから選ぶ。前の無線が話し終わるまで次は待つ
- シェアの連鎖：共有リンクの `?k=` に「何人目か」と前任者の記録（時:分・見逃し件数）を撹拌して入れる。9人ごとに特別版
  - 1〜8人目：冒頭で番号を呼ばれる。切り替え直前の砂嵐と警備室のモニターに前任者（N−1人）が映る。4人目以降は「交代して」のつぶやき。最後に「あと、N人。」。結末に前任者の記録と空き枠
  - 9人目：前任者8人が記録付きで廊下に現れ、映像と声が壊れていき、警備室で囲まれ、「信号なし」で途切れる
- 目を離した人（タブを離れた人）：離れた瞬間に耳元で「目を、離しましたね？」。タブ名が変わり続ける。戻ると不在時の録画が再生され、人影がカメラの真下まで歩いてくる。以後その人影は消えず、声はどんどん壊れる。結末に目を離した秒数
- 何度も遊ぶ人（この端末での回数）：2回目・3回目・4回目・5回目以降で冒頭の無線が変わる。3回目以降は警備室の無線が変わり、無線の声そのものも少しずつ壊れる

## 素材

- 声：Gemini 3.8 Flash TTS（`gemini-3.8-flash-tts`）。`python tools/gen_voices.py --env <GEMINI_API_KEY を書いた .env>` で作り直せる（キーはこのリポジトリに置かない）。無線は Charon、ささやきは Enceladus、前任者は Algenib / Achernar / Gacrux / Umbriel
- 写真：GPT Image 2（Codex 内蔵 image_gen）。廊下・警備室の背景（img/corridor.jpg・img/room.jpg）、人物（img/fig_*・guard_*）、物（img/obj_*）。人物と物は `python tools/prep_sprites.py` で切り抜いて WebP に。依頼書とプロンプトは work/ に
- 効果音・環境音：外部素材なし。Web Audio で合成（換気扇・足音・ドアのきしみ・無線の切れる音・映像の乱れ）
- 映像の乱れは横ずれ・色ずれ・ブロック崩れ・停止で表現し、白い全面点滅は使わない
